# Alt-Mobility-Project
This Project contains the SQL queries, visualizations, and analytical summary for the Customer Retention by Cohort analysis conducted for Alt Mobility. The objective of this project is to evaluate customer loyalty trends over multiple years and derive actionable insights to support strategic decision-making.

# Project Objectives
Analyze repeat customer behavior using cohort-based retention analysis.
Use SQL to extract insights from customer purchase data.
Visualize customer retention patterns across multiple years.
Summarize key findings and provide recommendations.

#  Approach
🛠 SQL Analysis
All SQL queries are provided in the ANALYSIS.sql file.
Queries include cohort grouping, customer retention counts, and time-based tracking of repeat purchases.
Data cleaning was minimal as the dataset was assumed to be clean.

# Key Insights from SQL:
High initial retention for 2020 and 2021 cohorts.
Gradual decline in customer returns over time, typical of natural churn.
Sharp drop in cohort size after 2022, possibly due to lower acquisition or retention issues.

# Observations:
The 2020 cohort had the highest lifetime value with 699 repeat purchases over 6 years.
Recent cohorts (2023–2025) show reduced retention, indicating a need to re-evaluate onboarding or loyalty strategies.

# Recommendations:
Introduce targeted re-engagement campaigns for recent cohorts.
Investigate and optimize the customer journey for new users.
Consider loyalty incentives for long-term customers.
